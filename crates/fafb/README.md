# fafb

Name-hold. This crate is empty on purpose.

FAFb is the compiled binary form of `.faf` — the IANA-registered
`application/vnd.faf+yaml` context format. The registration is `.faf`'s; the
binary builds on it.

The format is implemented in **[faf-fafb](https://crates.io/crates/faf-fafb)**.

```bash
cargo add faf-fafb
```
